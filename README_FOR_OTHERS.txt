HOW TO RUN DEEPFAKE VOICE DETECTOR
==================================

1. PREREQUISITES
   - You must have Python installed (Version 3.10 or newer).
   - Get it here: https://www.python.org/downloads/

2. HOW TO RUN
   - Double-click the file named: setup_and_run.bat
   - It will automatically:
     a) Create a secure folder for libraries (.venv)
     b) Download all necessary AI models and tools
     c) Start the application

3. TROUBLESHOOTING
   - If the window closes immediately, open "setup_and_run.bat" in a text editor
     and inspect the code, or run it from a command line to see errors.
   - Make sure your internet connection is active for the first run (to download libraries).
