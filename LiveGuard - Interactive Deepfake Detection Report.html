Synchronous Audio-Visual Analysis for the Detection of Synthetic Media in Real-Time Conferencing

This project introduces LiveGuard, a desktop application designed to detect deepfakes in live video calls. As AI-generated synthetic media becomes indistinguishable from reality, it poses a significant threat through misinformation and fraud. LiveGuard provides a first line of defense by analyzing both video and audio streams simultaneously for signs of manipulation.

System Architecture

Click on each stage of the pipeline to learn more about the process.

🖥️

1. Live Capture

The application captures the video call directly from the screen and system audio.

This initial stage uses a multi-threaded approach. One thread captures a designated screen region using the `mss` library. Two separate audio threads use `soundcard` to capture both system output sound (the other caller) and the local microphone input. This ensures all parts of the conversation are monitored in parallel.
↓
🧠

2. Parallel Processing & Analysis

Video frames and audio chunks are processed in-memory for low-latency analysis.

To achieve real-time performance, all data is handled in-memory, avoiding slow disk I/O. Video frames are passed to Google's MediaPipe for facial landmark detection. The cropped face is then sent to an EfficientNet model. Simultaneously, audio chunks are converted to Mel spectrograms and fed into a Transformer model. This parallel pipeline minimizes delay.
↓
📊

3. Score Fusion & Verdict

Scores from video and audio models are averaged to form a final, robust verdict.

The system employs a score-level fusion strategy. The 'fake' probability scores from the video model, system audio model, and microphone audio model are collected. These scores are then averaged to produce a single, balanced confidence score. This approach prevents a single model's error (a false positive) from incorrectly dominating the final result.
↓
📈

4. Live Overlay UI

Results are displayed in real-time on a desktop overlay window.

The final output is an always-on-top window created with OpenCV. It shows the live screen capture, an intricate face mesh, and the real-time scores for video, system audio, and microphone audio. The final verdict is color-coded (Green, Yellow, Red) based on a tiered threshold system, providing a clear, at-a-glance assessment of the video call's authenticity.

Key Technologies & Models

The project is built on a foundation of powerful deep learning models and libraries.

🎞️

EfficientNet

A high-performance CNN for detecting visual artifacts in faces, trained on FaceForensics++.

🔊

Transformer

A self-attention-based model for analyzing voice patterns, trained on ASVspoof2019.

🕸️

MediaPipe

Google's framework for fast and detailed 468-point facial mesh tracking in real-time.

🐍

Python & PyTorch

The core programming language and deep learning framework for the entire application.

Conclusion & Future Work

Project Achievements

This project successfully evolved from a file-based web tool into a low-latency, multimodal desktop application capable of analyzing live video calls. The integration of parallel audio/video processing and in-memory analysis demonstrates a viable architecture for real-time deepfake detection, achieving a critical proof-of-concept.

Scope for Future Work

  • Continuously retrain models with newer, more diverse datasets.
  • Develop a full GUI for user-friendly screen region selection.
  • Optimize models further for deployment on lower-power devices.
  • Explore more advanced score fusion algorithms.
